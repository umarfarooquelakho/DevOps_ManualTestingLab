# DevOps Manual Testing Lab — SCD Lab 12 & 13

A simple front-end student login demo for performing manual testing and logging defects through GitHub Issues.

## Run
Open `index.html` in a web browser. No installation is required.

## Demo credentials
- Username: `student`
- Password: `Test@123`

**Important:** These credentials are hard-coded solely for classroom demonstration. This is *not* a production authentication system; do not use it to protect real data.

## Lab workflow
1. Create a GitHub repository called `DevOps_ManualTestingLab` and upload these files.
2. Open `index.html` locally and perform the test cases from the accompanying workbook.
3. Fill in the Actual Result and Pass/Fail status based on what you observe.
4. If any test fails, record the details and screenshot in GitHub Issues, citing its Test Case ID.
5. Optional GitHub Actions workflow validates presence of the sample files; it does *not* execute manual tests.

## Submission evidence
Take screenshots of repository, running application, test execution, test case workbook, and any reported GitHub Issues.
